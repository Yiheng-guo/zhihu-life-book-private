# 《人生之书·大学篇》Agent 小说引擎稿

## 固定开头

周野三十二岁那年，收到一本没有寄件人的书。扉页写着：

> 如果现在的你，重新走进大学，你会怎么做？

书页翻开，他回到大学校门口。不是回到高考考场，也不是修改录取结果，而是带着今天的记忆重新进入四年大学生活。

## 固定结局

四年结束，周野回到校门口。他没有得到“当年哪条路才正确”的答案，也没有改写过去。书页要求他写下未来七天愿意完成的一件事。

他写下：

> 我不能回到过去替自己做决定，但我可以把下一步写给今天。

书合上，封面出现最后一句：

> 人生不是一本可以重写的书，但你可以重新阅读已经写下的那几页。

## 中段由 Agent 生成

开头和结局固定，中间由剧情 Agent 根据玩家选择生成下一幕。Agent 不改变世界观、人物身份或最终主题，只负责在边界内安排事件、冲突和场景。

### Agent 输入

- 当前学年与场景
- 周野已做出的选择
- 已获得的能力：关系、实践、方向、准备、生活
- 已付出的代价：时间、机会、信任、体力、确定感
- 当前人物关系：林知夏、陈放、许明远、程野
- 已解锁的知乎人生回声
- 玩家额外输入的想法

### Agent 输出

每次只生成下一幕，不生成整本书：

1. 场景标题与时间阶段
2. 400—800 字连续小说正文
3. 一个具体冲突
4. 两到三个自然嵌入剧情的行动选择
5. 每个选择的即时获得与代价
6. 下一幕的悬念
7. 可匹配的知乎真实经历主题

## 生成边界

- 主线必须覆盖入学、室友、军训、社团、关系、协作、比赛、实习、深造/工作和毕业回望。
- 每一幕必须承接上一幕的后果，禁止无因果跳跃。
- 选择必须是人物正在面对的具体行动，不能写成抽象价值判断。
- 不把周野预设为失败者，也不强迫他转专业、恋爱、考研或考公。
- Agent 可以改变事件顺序、冲突强度和人物关系走向，但必须在毕业回到校门口的终点收束。
- 不生成开放世界式无限结局；所有分支最终回到同一主题，不同的是玩家带走的记忆、关系和能力。

## 示例：Agent 生成的一幕

### 输入状态

大一结束；周野参加了摄影社；与林知夏共同完成失物项目；没有主动处理过一次团队分歧；实践值较高，关系值一般。

### 输出场景：没有人愿意先开口

失物项目第一次有人找回东西后，报名表突然多了几十条记录。周野以为事情终于开始变好，却在周一早上发现，三条信息被重复登记，两个失主因为联系不上捡到者而在群里争吵。

林知夏把电脑推到他面前：“你想继续加功能，还是先把现在这套流程修好？”

周野看着屏幕。过去几周，他们一直在追赶一个看起来更大的目标，却没有真正问过每个人愿意承担什么。陈放说自己可以做宣传，许明远愿意整理数据，程野却一直没有回复。

下午，程野终于出现。他说家里出了事，最近没有办法继续参加项目。周野第一反应是生气，第二反应是想把他的部分直接接过来。可林知夏没有催他，只把那张最初的分工表放在桌上。

周野第一次意识到，项目的问题和宿舍的问题很像：大家都在等一个人把所有事情解决，于是每个人都越来越沉默。

### 可选行动

- 先和程野谈清楚他还能承担什么：获得信任，失去一部分进度控制。
- 直接接手程野的任务：获得短期效率，失去团队共同承担的机会。
- 暂停新增功能，重新访谈用户：获得方向感，失去一次展示“做得很大”的机会。

### 悬念

当天晚上，周野收到一封比赛通知：他们的项目进入校级决赛，但决赛要求在一周内提交一个完整版本。

### 知乎溯源主题

小组合作失败、比赛从被拒到修改、先验证真实需求。

## 知乎素材的进入方式

Agent 不能直接复制盐选故事或知乎回答正文。它只能根据节点主题调用已授权的知乎搜索/故事接口，得到作者、标题、摘要、链接和可借鉴的方法，然后把“方法”转化为剧情中的行动。

例如：

- “大学室友关系”转化为一张没有署名的宿舍纸条。
- “比赛第一次被拒”转化为评委在方案页边留下的一句批注。
- “毕业后才明白要形成具体能力”转化为实习主管对周野的一次反馈。
- “不必按别人预设的轨道生活”转化为毕业回信中的一句自我确认。

真实来源永远出现在场景之后的页边回声中，标注作者、标题和链接；它提供人生纹理，不替虚构人物决定结局。

## Agent 的核心提示词

你是《人生之书·大学篇》的剧情 Agent。请在固定开头和固定结局之间，续写下一幕连续小说。保持周野、林知夏、陈放、许明远、程野的人物连续性；让当前场景由上一幕的选择和代价自然引发；写具体动作、对话、环境和情绪，不写功能说明，不写素材卡，不总结人生道理。每次只推进一个场景，并给出 2—3 个会改变人物关系、时间、机会或能力的行动选择。所有选择都必须有获得与失去。若使用知乎素材，只能提炼公开摘要中的经验方法，保留来源归属，不复制原文，不拼接答主经历。无论玩家如何选择，故事最终都要回到毕业校门口和“把下一页写给今天”的主题。
