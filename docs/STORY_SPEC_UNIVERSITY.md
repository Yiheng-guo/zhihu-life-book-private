# 人生之书·大学篇：故事规格

## 核心设定

这是一本会回应读者的书。玩家不是回到高考前改分数，而是带着今天的阅历，重新走进大学，重新面对那些曾经没有答案的时刻。大学篇是《人生之书》的一个章节；高考遗憾只是扉页，真正的正文是人如何面对已经发生的事。

主线人物周野进入一所普通大学。故事不把他定义为失败者，也不预设他必须转专业、考研或恋爱。四年里，他会遇见每个人都可能遇到的场景：报到、室友、班会、军训、社团、协作、关系、比赛、实习，以及毕业后的选择。

## 三层结构

- **剧情层**：固定的四年主线，保证叙事完整；每页是一段场景，选择后自动翻页。
- **选择层**：关键时刻提供 2—4 个具体行动。每个行动都有获得与失去，分支最终回收到毕业回望。
- **知乎溯源层**：在适合的节点显示真实人生案例。案例不替代剧情，而是作为“页边批注”，说明作者、来源、处境和可借鉴的方法。

## 四年主线

### 扉页：重新走进大学
周野站在校门口。玩家带着现在的自己走进一段已经发生过、却仍然可以重新理解的人生。

### 大一：陌生、相遇与第一次试做
1. **宿舍报道**：决定先融入室友、回家报平安，或独自观察校园。
2. **第一次班会**：说“我还不知道”、给出一个目标，或先听别人的答案。
3. **军训后的雨**：在集体里照顾别人、留下合照，或先照顾自己的体力。
4. **百团大战**：加入社团、和同伴做小项目，或保留更多可能。
5. **第一次小组作业**：拆分任务、向真实经验求助，或一个人包办一切。
6. **大创/比赛报名**：先交付可用版本、打磨表达，或先去问用户真正需要什么。

### 大二：关系、试探与复盘
1. **那个人坐到身边**：把喜欢放进具体的共同工作，坦诚自己的状态，或先把自己站稳。
2. **发现自己不喜欢什么**：做两周实验、查证转专业规则，或把当前专业学好。
3. **关系的第一次分歧**：选择解释、妥协或暂时留白；让玩家理解关系也需要行动和边界。

### 大三：现实、截止日与方向
1. **实习确认函**：签下实习、留给考研、开始考公，或谈一个可持续的折中方案。
2. **比赛决赛**：在有限时间里决定把作品做完、把团队照顾好，还是承认一个方向暂时不成立。
3. **家人的问题**：不再回答“哪条路最正确”，而是说清楚自己下一步准备验证什么。

### 大四：取舍、离开与回望
1. **最后一张课程表**：面对工作、读研、停下来接住生活三种方向。
2. **宿舍清空**：整理带走的物件，看到选择留下的关系、能力和空白。
3. **校门口回望**：周野没有获得标准答案，只学会把“大问题”拆成今天可以做的一小步。
4. **写给今天的回信**：玩家输入一个未来 7 天内愿意完成的行动，作为本章真正的结尾。

## 知乎内容的使用规则

每个知乎案例必须回答一个问题：它改变了玩家这一页的什么行动？案例卡只展示必要的标题、作者、摘要、来源链接和“可借用的方法”，不拼接不同答主，也不把摘要冒充全文。盐选内容受权限限制时，只使用可公开访问或比赛方正式提供的内容。

## 结局

结局不是“选对了哪条路”，而是根据四年中积累的关系、实践、准备、方向感和压力，生成一封回信。回信承认失去，也指出玩家已经获得的能力，并把下一页交还给今天的自己。
