# 《人生之书·大学篇》

周野收到那本书是在一个下雨的晚上。

书没有寄件人，封面是旧羊皮纸的颜色，边角磨得发白。打开以后，扉页上只有一行字：

> 如果现在的你，重新走进大学，你会怎么做？

周野盯着那句话看了很久。他已经离开大学很多年，久到校门的样子只剩下一些模糊的颜色。可他仍然会在夜里想起那场考试，想起志愿表上被家人圈出来的专业，想起自己后来无数次说过的那句“如果当时……”。

书页翻动了一下。

雨声忽然远了。

他站在一所大学的校门口，手里拎着一个旧行李箱。门口的树还没有长高，石阶上有新生拖行李留下的水痕。一个年轻的母亲替孩子整理衣领，父亲举着手机拍照，孩子不耐烦地说：“知道了，你们回去吧。”

周野低头看自己的录取通知书。上面的专业并不特别，学校也不是他曾经幻想过的地方。可这一次，他没有感到羞耻，也没有急着证明什么。

他只是想知道，如果把今天的自己放回那一天，能不能多看见一些当时看不见的东西。

“到了记得报平安。”身后传来母亲的声音。

周野回头，看见她站在校门外。她没有再往里走，只把手里的水递给他。

“先去宿舍。”他说。

三零二住着三个陌生人。陈放把一箱书摔在地上，许明远正在研究校园网，林知夏蹲在窗边擦桌子。四个人互相介绍姓名、家乡和专业，像在完成一场并不熟练的仪式。

陈放问：“你们以后想干什么？”

没有人回答。

夜里，周野给母亲发语音：“我到了，宿舍挺好的，你放心。”他本来还想说自己会认真学习、会照顾好自己、会有一个很好的未来，可这些话到了嘴边，只剩下一句“你早点睡”。

第二天清晨，三零二第一次发生了争执。许明远的闹钟响了三遍，陈放在床上骂了一句，林知夏把被子蒙过头。周野看着那只不停震动的手机，想起自己曾经以为大学生活会从某个宏大的梦想开始，没想到第一件需要解决的事，是谁来关掉闹钟。

他没有立刻发火。晚上回宿舍时，他在桌上放了一张纸：“闹钟能不能放近一点？卫生也一起排一下？”

纸条下面很快多了一行字：

“可以。周末一起买垃圾袋。”

三零二没有因此变成一个理想的家，但他们第一次共同决定了一件小事。周野后来才明白，很多关系不是从轰轰烈烈的相遇开始，而是从一句不太好意思说出口的话开始。

第一次班会上，辅导员让每个人说说为什么选择这个专业。轮到周野时，他看见讲台下几十张陌生的脸，忽然想起志愿填报那天。家里人说这个专业以后好就业，老师说分数够不上更好的学校，周野点了点头，就把它填了上去。

“我叫周野，来自……”他说到这里停了一下，“至于为什么选这个专业，我还没有完全想明白。”

教室安静了两秒。

散会后，一个男生追上来，说自己也不知道。那男生叫程野，后来会成为他们比赛队伍里最晚离开实验室的人。

军训最后一天，雨从天空砸下来。队伍解散后，大家挤在屋檐下。林知夏把一瓶水递给周野：“你一直没喝。”

班级要拍合照。周野本来准备回宿舍，走了几步又折回来，站进了队伍。快门按下的瞬间，雨水在镜头上留下了一片模糊。那张照片后来一直压在他的书里，像一扇没有关严的窗。

十月的百团大战把操场变成一座嘈杂的城市。周野加入了摄影社，林知夏却拉他去做一个校园失物项目。他们先做了一张表格，发到班级群里，整整一天没有人使用。

“是不是我们做得太麻烦了？”周野问。

“先去问问他们为什么不用。”林知夏说。

他们在食堂门口拦住同学，听见各种各样的回答：不知道去哪找、懒得填、找到了也不想回复。周野第一次发现，一个想法不是因为写在纸上就成立，它要经过别人的生活，才知道自己有没有用。

那段时间，周野常常在图书馆待到闭馆。他以为自己在寻找方向，其实只是在等待方向主动出现。一天晚上，林知夏合上他的书：“别急着证明自己选对了。先做两周，看看你愿不愿意继续。”

两周后，项目仍然粗糙，却终于有几个同学真的用它找回了东西。

期末前，小组作业又一次把他们推到一起。文档只剩三天截止，群里却没有人说话。周野差点把所有任务都接过来，程野却把电脑转向他：“你要是全做了，我们下次还是什么都不会。”

他们把任务拆开，第一次认真确认每个人到底能交付什么。许明远卡在开头，周野没有替他写完，而是陪他把问题拆成三个更小的问题。作品最后只拿到中等分数，可那天凌晨，四个人在空教室里吃着冷掉的包子，忽然都觉得这件事确实属于他们。

大二开学后，林知夏坐到了周野旁边。她准备参加比赛，周野帮她改方案。两个人一起吃饭、一起赶末班车，也开始因为一些小事争吵。

有一次，林知夏问：“你是不是觉得，只要不把话说清楚，就什么都不会失去？”

周野沉默了很久，说：“我喜欢和你在一起，但我不知道以后会怎样。”

“我也不知道。”她说，“可不知道不代表不用说。”

他们在一起过一段时间，也认真地分开过。没有谁做错了什么，只是一个要去实习，一个要准备考试，原本并肩的路慢慢有了不同的方向。分开那晚，林知夏把那张雨里的合照还给他：“别把这几年只记成结果。”

周野把照片夹进书里。

大三时，所有人开始谈论未来。程野准备考研，许明远研究考公，陈放已经开始投简历。周野同时收到一份实习邀请和一张比赛报名表。家里问他到底想走哪条路，他第一次没有急着给出一个听起来正确的答案。

他去了实习公司。

第一天的工作并不光鲜：修改、等待、重复确认，还有一场没有人鼓掌的会议。可当一个用户告诉他“这个功能让我少走了一次弯路”时，他忽然想起大一那个没有人使用的表格。

原来方向不是突然降临的，它藏在一次次愿意继续做下去的时刻里。

比赛决赛前一周，团队因为作品方向争吵起来。有人想把页面做得漂亮，有人坚持先把功能做完，还有人已经连续几天没有睡觉。周野把方案重新拆开，只保留一个能运行、能被人理解的版本。

他们没有拿第一名。

评委说：“你们还不成熟，但确实在回答一个真实的问题。”

回去的路上，程野问：“你失望吗？”

周野说：“有一点。但我更怕我们为了看起来厉害，忘了自己为什么开始。”

大四那年，周野拿到了一份工作机会，也拿到了研究生录取通知。两封信放在桌上，像两扇都没有标注出口的门。他想起自己曾经多么渴望一张纸替他决定人生，后来才知道，任何录取、成绩和奖项都只能替人打开一扇门，不能替人走完门后的路。

他选择先去工作，并给自己留下一年重新评估的时间。

毕业前夜，三零二只剩下几个纸箱。陈放要去南方，许明远准备考试，程野提前离校。周野把宿舍卫生表、比赛方案、雨天合照和那瓶空掉的水放进行李箱。

林知夏没有来送他，只发来一条消息：

“祝你下一页写得比这一页诚实。”

第二天，周野回到校门口。新生正在进来，父母站在门外拍照。四年前，他也是这样站在这里，以为人生会被某一次考试决定；四年后，他终于知道，过去确实会留下痕迹，却不会独占解释一生的权利。

书页上浮现出一行字：

> 你无法同时拥有所有东西。每一次选择都会带来获得，也会带来失去。

周野拿起笔，在最后一页写下：

“我没有得到一个证明当年没有选错的答案。但我知道，今天可以先做一件事。”

他写下了自己的行动。

书页没有告诉他这一步会通向哪里。它只是慢慢合上，在封面上留下新的标题：

> 下一页，写给现在。

而那些来自知乎的真实人生，不再是替周野安排结局的答案。它们像书页边缘留下的手写批注：有人曾经因为不敢开始而错过，有人从失败里重新找到方法，有人在毕业后才学会按自己的方式生活。

周野读完那些批注，合上书，走进今天。
